## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues at `Aermberry/data_mover` (created from this repo). All create/read/label/close operations go through the `gh` CLI — see `docs/agents/issue-tracker.md`.

### Triage labels

Default mattpocock five-role vocabulary is in use: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Mapping in `docs/agents/triage-labels.md`.

Single-context. Read `GLOSSARY.md` and `docs/adr/` when relevant; consumer rules in `docs/agents/domain.md`.
